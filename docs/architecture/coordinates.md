# 座標系

MMD 互換のためには、座標系の扱いを 1 か所にまとめ、あちこちで軸を反転しないことが重要です。この文書はその約束事をまとめます。背景は [ADR 0002](../adr/0002-left-handed-model-space.md) を参照してください。

## モデル空間

実行時のモデル空間は、PMX / PMD ファイルの空間とまったく同じです。

| 項目 | 値 |
| --- | --- |
| 手系 | 左手系 |
| 上方向 | +Y |
| キャラクターの正面 | -Z 方向を向く |
| +X | キャラクターから見て左 |
| 単位 | MMD の単位（1 単位 ≒ 8 cm。身長は 20 前後） |

- ファイル内のボーン位置は、モデル空間での絶対位置です。
- ボーンの初期の相対位置は「自分の位置 − 親の位置」です。
- クォータニオンもこの空間のまま扱います。
- 読み込み時に軸を反転することはありません。

## エディタカメラ

エディタカメラは同じ空間で `look_at_lh`（左手系の視点行列）を使います。

- 方位角 0 のとき、カメラは -Z 側にあり、キャラクターの顔を見ます。
- 既定値は距離 12、仰角 20°、垂直画角 45° です。距離は 0.25〜400、仰角は ±89° に制限します。
- 操作: 右ドラッグで回転、中ドラッグで平行移動、ホイールでズーム、Home キーでリセット。
- 手前・奥のクリップ面は、カメラの距離に応じて広げます。カメラを引いたときにモデルの奥側が切れないようにするためです。

グリッドは XZ 平面にあり、座標軸の色は +X が赤、+Y が緑、+Z が青です。

## クリップ空間（wgpu）

ビューポートのクリップ行列を作るのは `mmd_core::coordinates::wgpu_clip_from_view` だけです。

1. 左手系のビュー行列を受け取る
2. `Mat4::perspective_lh`（深度範囲 0〜1。wgpu の規約と同じ）を掛ける
3. 画角・アスペクト比・クリップ面・結果の行列が有限であることを確かめ、不正ならエラーを返す

既定のカメラ位置（-Z 側）から見ると、ワールドの +X は画面の右、つまりキャラクターの左になります。ほかのモジュールで軸を反転することはありません。

VMD のカメラモーションに従うときも、同じ関数でクリップ行列を作ります（[animation.md](animation.md) の「カメラ」を参照）。

## 物理での回転の扱い

剛体とジョイントの回転（ファイルに 3 つの角度で保存）は、`Ry × Rx × Rz`（Direct3D の yaw・pitch・roll の順）で合成します。詳しくは [physics.md](physics.md) を参照してください。

## MMD 本体との照合

左手系の扱いは、公開されている PMX の仕様と、`mmd-core` の射影のテストに基づいています。ボーンの姿勢、IK、描画結果は、MMD 本体と数値で照合していません。
