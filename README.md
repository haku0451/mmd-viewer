# MMD Viewer

MMD Viewer は、MikuMikuDance（MMD）の素材との互換性を目指す、Windows 向けのデスクトップビュワーです。

PMX / PMD モデルを読み込み、VMD モーションを再生し、Bullet による物理演算と MMD 互換のシェーディングで描画します。

## できること

- PMX 2.0 / 2.1・PMD モデルの読み込み（複数モデルを同時に表示可能）
- VMD モーションの再生（ボーン、モーフ、IK の ON / OFF、表示 / 非表示、カメラ、ライト）
- 音声（wav / mp3 / ogg / m4a）をモーションに合わせて再生
- Bullet 3.25 による剛体・ジョイントの物理演算（髪、スカート、アクセサリー）
- MMD の標準シェーダーと同じ式によるトゥーンシェーディング、スフィアマップ、輪郭線、地面影、セルフシャドウ
- Direct3D 12 を優先した GPU 描画（wgpu）

## 操作

| 操作 | 内容 |
| --- | --- |
| ファイル → モデルを追加 | PMX / PMD モデルを読み込む |
| ファイル → モーションを適用 | VMD モーションを、選択中のモデルに適用する |
| ファイル → 音声を開く | 音声を読み込む |
| ファイル → 選択中のモデルを外す | 選択中のモデルを取り除く |
| ウィンドウへのドラッグ＆ドロップ | 拡張子に応じてモデル・モーション・音声として読み込む |
| 左パネルのモデル一覧 | クリックしたモデルが、モーションの適用先になる |
| 再生 / 一時停止 / 停止 | 再生する / その場で止める / フレーム 0 に戻る |
| 表示 → カメラをリセット | エディタカメラを初期位置に戻す |
| 表示 → カメラモーションに従う | VMD のカメラを使う（透視投影のキーのみ） |
| 表示 → 地面影 / セルフシャドウ | 影の表示を切り替える（既定: 地面影 ON、セルフシャドウ OFF） |
| 表示 → 物理ON/OFF / 物理リセット | 物理演算の切り替え / 剛体をモーションの姿勢に戻す |
| 表示 → 30 FPS / 60 FPS / 無制限 | 表示のフレームレート（モーションは常に 30 フレーム/秒） |
| ビューポート上部のボタン | 舞台（別ウィンドウ表示・全画面）、情報、座標軸の表示 |
| 右ドラッグ | カメラの回転（カメラモーションに従っていないとき） |
| 中ドラッグ | カメラの平行移動 |
| マウスホイール | ズーム |
| Home（ビューポート上） | カメラをリセット |

UI は日本語です。文字の表示には、游ゴシック、メイリオ、MS ゴシックのいずれかを使います。

## ビルド

対象は Windows 10 / 11（x86_64）、MSVC ツールチェーンです。物理演算の Bullet は Git サブモジュールなので、サブモジュールごと取得してください。詳しくは [docs/development/building.md](docs/development/building.md) を参照してください。

```bash
git submodule update --init vendor/bullet3
cargo check --workspace
cargo test --workspace
cargo run -p mmd-viewer            # 開発ビルド
cargo run --release -p mmd-viewer  # 速度を確かめるときはリリースビルド
```

ログは標準エラー出力と `logs/` 以下に出力します。環境変数 `RUST_LOG` で、既定のフィルタ `info,wgpu_core=warn,wgpu_hal=warn,naga=warn` を変更できます。

## 制限事項

- 姿勢、IK、物理、描画結果は、MMD 本体と数値で照合していません（肌の色の 1 例を除く）。
- 物理の反復回数と刻み幅は、手元の配布モデルで調整した値です。網目状につながったスカートは静止時もわずかに揺れ、速い動きでは小さな剛体が体にめり込むことがあります。
- 「物理後」に変形するボーンは、物理の結果を待たずに同じ評価で計算します。
- 外部親ボーンは評価しません。
- 追加 UV は読み込みますが使いません。ローカル軸は変形に使いません。
- 輪郭線（反転ハル）、セルフシャドウ（深度マップ 1 枚）、地面影（y = 0 への投影）は MMD とは異なる方式です。共有トゥーンが見つからない場合は、内蔵のグラデーションで代用します。
- テクスチャのミップマップは生成しますが、描画では最上位のレベルだけを使います。
- 平行投影の VMD カメラキーは使わず、エディタカメラのままにします（左パネルに表示）。
- VPD、PMM、MME（エフェクト）は未実装です。
- 起動時の GPU 初期化だけは UI スレッドを止めます。モデル・モーション・音声の読み込みは別スレッドで行います。
- Direct3D 12 を作れない場合は、wgpu の主要なバックエンドで再試行し、その旨をログと左パネルに表示します。
