# ADR 0002: モデル空間は左手系

## 背景

Phase 0 では、モデルファイルをまだ読み込んでいなかったため、エディタの空間を右手系にしていた。PMX と PMD は、位置とボーンの回転を左手系・Y 上の空間で保存している。キャラクターは -Z を向き、+X はキャラクターの左になる。IK やクォータニオンの補間は、その空間のまま行う必要がある。

## 決定

実行時のモデル空間を、ファイルの空間と同じにする。読み込み時に軸を反転しない。エディタカメラは `look_at_lh` を使い、方位角 0 では -Z 側に置いて顔がカメラを向くようにする。クリップ行列を作るのは `wgpu_clip_from_view` だけで、wgpu の 0〜1 の深度範囲をそのまま使う `perspective_lh` を掛ける。軸の反転はしない。

## 結果

- カメラ、グリッド、スキニング、モーション評価、物理が 1 つの空間を共有する。
- 将来のエクスポーターは、この空間をそのまま書き出せばよい。
- 姿勢を互換と呼ぶには、MMD 本体との数値の照合がまだ必要である。
