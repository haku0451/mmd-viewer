# ADR 0003: PMX・PMD・VMD を明示的なカーソルで読む

## 状態

採用

## 背景

プロジェクトの技術スタックでは、バイナリ解析に `binrw` を挙げている。しかし PMX はインデックスの幅（1・2・4 バイト）をヘッダーで決め、すべての個数を、メモリを確保する前に検査して拒否する必要がある。PMD と VMD は、固定長の文字列、省略可能な末尾のブロック、可変長の IK レコードが混ざっている。

## 決定

`mmd-format` は、これらのファイルを明示的なカーソル（`reader.rs`）で読む。カーソルは、配列を確保する前に残りのバイト数を確かめ、次の場合に型付きのエラーを返す。

| エラー | 内容 |
| --- | --- |
| `Truncated` | ファイルが途中で終わっている |
| `AllocationLimit` | 個数が上限を超える、または残りのバイト数で足りない（例: 頂点 200 万、インデックス 600 万、ボーン 16,384） |
| `BadIndex` | 存在しない頂点・ボーン・材質・剛体などを指している |
| `NonFinite` | NaN や無限大の値 |
| `BadText` | 宣言された文字コードで文字列を読めない |
| `BadIndexSize` | PMX のインデックス幅が 1・2・4 以外 |
| `UnsupportedVersion` | PMX 2.0 / 2.1、PMD 1.0 以外 |
| `BadMagic` | PMX・PMD・VMD のどれでもない |

## 結果

- 解析部は `binrw` に依存しない。規則的なレイアウトの形式を将来追加する場合は、`binrw` を使ってもよい。
- カーソルは `mmd-format` の中だけで使う。
